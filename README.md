# Algodif
### Data processing (**ALGO**)rithms for (**DIF**)fraction-based techniques 

Software for calibrating multi-elements Energy-Dispersive X-ray Diffraction detectors and processing data
at a hard X-ray synchrotron beamline.

Features
--------
- Developed methods for peak detection and sub-pixel location.
- Developed methods for matching measured peaks vs reference peaks
- Methods for energy calibration of GeRM detector.
- Methods for Q-calibration of GeRM detector.
